# 评测协议（尚无真实学生研究结果）

从界面导出教师 JSON，再运行 `python3 scripts/evaluate.py export.json`。独立正确率只计 INDEPENDENT_PRACTICE 且没有请求过提示/白板干预的答题事件。原始记录保留状态、方法、置信度和事件 ID；精确多项式等价只校验最终表达式，不判定推导过程。

| 指标 | 当前状态 | 后续采集 |
|---|---|---|
| 独立解题正确率 | 有实测事件才输出 | 相同难度的保留题 |
| 知识变化 | 记录逐次结果；非已验证掌握率 | 前测/后测对齐 |
| 错误诊断准确率 | null | 双人专家标注与一致性检查 |
| 介入时机 | 有事件时间；质量未测 | 学生/教师盲评 |
| 一周保持率 | null | 七天后的独立延迟测试 |
| API 成本 | 配置价格估算 | 对照供应商账单；60 分钟真实课堂 |
| 平均延迟 | 模型请求时长 | 区分网络/视觉/语言输出 |
| 长期记忆检索准确率 | null | 构建带标准答案的历史检索集 |

基线：设置页选择 baseline，新建对应课堂。复用同一模型配置、历史上限、教材检索和成本限制；跳过教学策略和客观自动评分。它是消融入口，尚不是严格等预算随机实验。正式比较需要固定题目、总 Token、交互时间、初始水平，预注册主要指标并保护学生隐私。不要用演示模式比较 LLM 教学效果。
