# 课堂整合验收

2026-10-31。语音、原生 SVG 白板、区域核对和教学动作接口已合入主分支。当前开发重点是课堂交互，老师知识和模型调优留到下一阶段。

## 交付

- 连续白板、可收起讲解栏、紧凑工具栏和固定课堂控制。常驻教程、装饰卡片及语音技术测量说明已移除。
- 学生直接书写，支持整笔擦除、撤销重做、框选、缩放和移动；教材在同一课堂打开，返回后保留白板。
- 教学动作逐步落到白板，保存后回传执行记录。载入期间延后执行，避免白板尚未解锁时启动。
- 插话事件暂停板书，确认新问题后取消旧轮未完成动作；忽略旧会话、旧轮次和重复事件。
- 学生选区绑定保存后的修订、笔迹 ID 和截图。核对后的转录保留来源，由独立教学策略处理。
- macOS Apple Silicon 桌面应用已重新打包。
