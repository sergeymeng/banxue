# 一对一课堂：共同产品约定

学生在同一课堂里听讲、书写和提问；老师结合当前题目与学生步骤讲解、写板书。界面以正在进行的课为中心，设置与用量放在辅助入口。

## 模型

第一阶段以 Qwen 云端作为默认适配和验收对象。文本、视觉、ASR 与 TTS 保持独立接口；使用者自带 Key，地域、模型和价格可配置。应用预设必须由用户明确选择，不覆盖已有设置。模型能力通过真实样本验证；演示与模拟调用明确标记。

## 课堂界面

- 中央白板始终是主要工作区，学生可用鼠标、触摸或笔直接写，工具清楚且可撤销。
- 当前题目、老师的板书和学生的步骤同时可见。老师与学生的笔迹有明确区分。
- 老师讲解与对话作为侧栏，支持收起。麦克风、停止老师、暂停和结束入口容易找到。
- 打开教材或核对识别结果后能回到同一题、同一块白板。窄屏保留书写空间。
- 展示实际的监听、思考、播放和暂停状态。没有假视频或虚构在线状态。

## 分工与接入

- 语音对话维护采集、播放、插话事件与真实服务适配。
- 白板对话维护课堂界面、书写与板书执行器。
- 手写对话维护区域转录、原图核对与视觉适配。
- 教学对话维护课堂策略、表达、板书提案和证据。
- 总协调对话维护跨模块接线、合并、共同文档与整课验收。共同设定由协调对话同步，使用者无需重复粘贴。

学生开口时先暂停本地声音和待执行板书；确认新问题后取消旧轮未执行内容。已生成、已播放与已写出的内容分别记录。学生确认识别结果只确认转录，不直接建立数学正确性或掌握程度。

## 首个验收场景

老师提出一道链式法则题并逐步写板书；学生直接在白板写下一步，随时问“为什么要乘三”；老师暂停旧讲解，结合当前题回应，再继续课堂。每个环节先通过可重复仿真，再进行真实 Qwen 与设备联调。
